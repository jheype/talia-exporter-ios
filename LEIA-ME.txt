TALIA EXPORTER iOS — CORREÇÃO DO UNLINK

Este ZIP contém os ARQUIVOS COMPLETOS: 6 para substituir e 1 teste novo.
Não é um patch nem o projeto inteiro.

COMO APLICAR
1. Extraia o ZIP em uma pasta separada.
2. Copie cada arquivo para o mesmo caminho dentro do seu projeto talia-exporter-ios.
   Substitua os 6 arquivos existentes e adicione UnlinkRecoveryTests.swift.
   Preserve os demais arquivos do projeto. No Finder, NÃO substitua as pastas
   TaliaExporter ou TaliaExporterTests inteiras: copie os arquivos dentro delas.
3. Na raiz do projeto, execute: xcodegen generate
   Isso inclui o novo arquivo de testes no projeto do Xcode.
   Se XcodeGen não estiver instalado: brew install xcodegen
4. Abra TaliaExporter.xcodeproj no Xcode 16.4 ou mais recente.
   Selecione o esquema TaliaExporter, um simulador instalado e rode os testes
   com Product > Test. Depois gere/instale a nova versão pelo fluxo habitual.
